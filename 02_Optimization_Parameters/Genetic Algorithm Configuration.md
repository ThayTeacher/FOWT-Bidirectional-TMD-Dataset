# Genetic Algorithm Configuration

This document provides supplementary information on the Genetic Algorithm (GA) configuration used for the evolutionary optimization of the bidirectional tuned mass damper (TMD) system presented in the associated manuscript.

## 1. Software Environment

- **Software:** MATLAB R2018
- **Toolbox:** Global Optimization Toolbox
- **Optimization solver:** `ga`
- **Parallel computing:** Enabled
- **Number of parallel workers:** 4
- **Vectorized evaluation:** Disabled

The optimization process was executed using parallel processing. A local parallel pool with four workers was employed to evaluate candidate solutions through FAST-SC simulations.

## 2. Optimization Problem

- **Number of design variables:** 14
- **Constraint tolerance:** 1e-6
- **Objective function:** Weighted combination of the standard deviations of the fore-aft and side-to-side tower-top deflections.

The optimization considers the mechanical parameters of two tuned mass dampers, TMDX and TMDY, acting in the fore-aft and side-to-side directions, respectively.

The design variables include the TMD mass, stiffness, damping, stroke limits, and mechanical stopper parameters. The complete definition of the design variables and their corresponding lower and upper bounds is provided in Table IV of the associated manuscript.

## 3. Genetic Operators

The following genetic operators were employed:

- **Selection method:** Roulette-wheel selection (`selectionroulette`)
- **Crossover method:** Scattered crossover (`crossoverscattered`)
- **Mutation method:** Adaptive feasible mutation (`mutationadaptfeasible`)
- **Best-fitness monitoring:** `gaplotbestf`

## 4. Configuration of the Selected GA Experiments

The GA configurations selected for the final analyses used:

- **Population size:** 40 individuals
- **Maximum number of generations:** 40
- **Crossover fraction:** 0.70
- **Mutation parameter:** 0.30
- **Elite count:** 4 individuals

These configurations correspond to the best-performing experiments reported in the associated manuscript.

## 5. Optimization Cases

Four final optimization cases were considered:

1. **Wind Profile 1** — TMDX mass upper limit: 22 t
2. **Wind Profile 1** — TMDX mass upper limit: 42 t
3. **Wind Profile 2** — TMDX mass upper limit: 22 t
4. **Wind Profile 2** — TMDX mass upper limit: 42 t

The corresponding optimized TMD parameters and optimization results are reported in the associated manuscript.

## 6. Parallel FAST-SC Evaluation

For each candidate solution generated by the GA, the corresponding TMD parameters were evaluated through FAST-SC simulations.

Parallel processing was enabled in MATLAB to allow multiple candidate solutions to be evaluated concurrently. Four local MATLAB workers were allocated for the optimization runs.

The FAST-SC input and output files associated with the final simulation cases are provided separately in the `03_Simulation_Data` directory of this repository.
